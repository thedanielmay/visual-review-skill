# Cover and title page checks

Load this file in Phase 3 when page 1 carries a cover or title treatment. These checks apply only to the cover page, not to body pages.

- **Cross-page background consistency** (`likely` to `confident`). Does the cover background differ from the body pages? It can be a deliberate full-bleed treatment. It can also be a background rule that reached the cover by mistake. Check the source for an explicit cover rule or design note. If neither explains the difference, flag `likely` FIX IF TIME and ask the user to confirm.
- **Cover content utilisation** (`likely`). Does a large zone of the cover stay blank, or hold only near-invisible decoration? Flag any cover where more than 40% of the area is blank or below 10% opacity decoration. This is not breathing room. Suggest extending the type across the width, adding a designed graphic, or using a full-width single-column layout.
- **Cover grid against full-width treatment** (`possible`). Does the cover reuse the body column grid with no override? A cover constrained to the body grid reads as a body page with a large title. Flag it so the user can confirm the grid was a choice. Not every design wants a full-bleed cover.
